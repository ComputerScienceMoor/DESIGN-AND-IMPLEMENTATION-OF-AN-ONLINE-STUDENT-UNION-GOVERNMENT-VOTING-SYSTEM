# DESIGN-AND-IMPLEMENTATION-OF-AN-ONLINE-STUDENT-UNION-GOVERNMENT-VOTING-SYSTEM
Awoloro Daniel Adedayo  (HNDSWD/24/022). 
The Online Student Union Government (SUG) Voting System is a web-based application designed to make student union elections easier, faster, more transparent, and more secure. The system enables eligible students to vote for their preferred candidates online without the need for traditional paper-based voting.

The platform provides a convenient and reliable way to conduct student elections within tertiary institutions. It allows administrators to manage elections, register candidates, verify eligible voters, monitor voting activities, and publish election results. Students can securely log in, view available candidates, and cast their votes electronically.
